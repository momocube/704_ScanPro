用 Unity Hub 加入本資料夾，開啟後選 `704 → 關卡工作台`。工作台提供直接按鈕選取的選取、純筆刷、矩形、方形、圓形與路徑工具；形狀工具按住拖曳拉出單一區塊，純筆刷沿游標連續塗畫。另有格線吸附、尺寸、群組、路徑點停留秒數／幀數、全關卡共用色彩、左右／上下鏡像、非 Play Mode 預覽與試玩，以及 2688×3840 場域 PNG 匯出。

右側「全關卡共用色彩」提供「關卡紅色飽和度（%）」及「過關藍色飽和度（%）」，調整後按「儲存全域色彩」。全部關卡共用同一設定，100% 保留原色、0% 為灰階；紅色只影響關卡內紅區（包含目前選中的 shutter 影格），藍色只影響遊戲實際成功過場。藍格、QR、淺藍及失敗紅色過場保持原色。遊戲成功時，平面、CAVE 與場域輸出共用同一過場效果；工作台不再提供手動預覽按鈕。設定存於 `Assets/ScanPro/Resources/704_GameColors.asset`；新建置會包含它，既有 EXE 不會自動更新。

工作台可開啟「左右對稱繪製」，拖曳平面畫布上的黃色垂直線或修改「對稱中心 X」設定中心位置（0.5 格為一階）。新放置的物件與移動路徑會鏡射到另一側；中心線改動不會搬動已放置物件。選取既有物件可按「鏡射複製到另一側」。鏡像模式下以右鍵刪除時，會同步刪除對稱位置同尺寸、同形狀的物件（不限制顏色），一次復原可還原整組；位在對稱軸上的物件只刪除一次。

新放置的藍色觸摸格可選「手動輸入」或「自動數字」。自動內容可選一般數字或只含加減的一次算式，並設定答案範圍、運算元範圍及依序／隨機分配；答案以整數結果計算且不得為負數。選取單一藍格也可切換自動／手動；手寫欄位空白時，切回手動會保留目前顯示內容。所有藍色觸摸格數字 **2、5、6、9** 都會加底線，包括算式中的數字。

**2026-10-07 已實作並經規則檢查：** 每一關的數字藍格都強制由小到大按，手動／自動、Pro／非 Pro 皆適用；錯按不完成、不扣心、不推進、不產生回饋。紅格蓋住藍格時依最上層紅格功能判定，只扣心且下層藍格不完成。

**入口與記分板在所有關卡固定，禁止放置任何物件與互動。** 工作台以紅色標示東小牆整面記分板禁放區，並標示入口；蓋章、尺寸調整、座標與完整循環移動路徑都不能佔用。工作台與 Unity Inspector 會拒絕誤放，輸出設定鎖定兩個固定面；建置時再次檢查。原有入口背景特效由系統固定繪製，不是關卡物件。

每關倒數限時為 **60 秒**。固定記分板已顯示五關組內進度 `1-5` 至 `5-5`（例如 `2-5` 是該組第 2 關）及剩餘秒數，倒數歸零時仍顯示。每五關組的安全區只會出現在地板（Floor／face 2）；工作台放置／鏡射／移動、Unity Inspector、關卡驗證與建置檢查都會拒絕超出地板的安全區。這項限制只規定位置，安全區範圍與觸碰效果仍未定義，不能據此推定為整面地板免傷或其他玩法。

預覽現在只在內容變更時重畫，暫停後重用紋理，播放更新上限 60 Hz；外部修改與復原會更新預覽。同機單次繪圖平均從約 61～69 ms 降至 0.9～3.4 ms，解析度和 QR 保持，30 組逐像素比對一致。這不是完整工作台 FPS，詳細量測見 [效能報告](docs/PERFORMANCE.md)。

Build 讀取 `Assets/ScanPro/Levels` 與 `Assets/ScanPro/LevelDrafts` 中勾選輸出的匯入關卡，依關號排序，直接引用原資產。工作台底部的「一鍵 Build EXE（已勾選輸出關卡）」會驗證關卡、更新試玩場景清單並建置；Unity 選單輸出也走同一流程，不建立範例關卡。輸出採台北當日日期與不重複序號命名，附 `關卡清單.txt`。按「開啟試玩場景」或直接在該場景進入 Play Mode，也會使用目前勾選的輸出清單。

工作台底部可一鍵建置目前勾選的輸出關卡；3D／CAVE 預覽按住右鍵拖曳旋轉，按「重設 3D 視角」回到初始角度。2026-10-12 修正相機改變後沒有更新 RenderTexture 的問題：暫停與播放中皆即時更新，不必切換視窗；旋轉只重繪相機，不重建遊戲畫布。CAVE 預覽使用 520×420 展開圖紋理，預設從房間外側第三人稱觀看；場域輸出仍使用 atlas。藍格數字／算式及底線在兩種視圖使用相同旋轉角度。隔離 Unity 工作台 GUI 驗證與限制見 [VALIDATION](docs/VALIDATION.md)。

**編輯圖 520×420；場域 atlas 2688×3840。** 原圖順時針旋轉 90°、放大 6.4 倍為 2688×3328，下方另留 512px 黑色，不能拉伸填滿。牆面數字以玩家站在場域內觀看時可正常閱讀為準；CAVE 與場域輸出藍格中的數字／算式及底線使用相同角度，平面編輯文字維持原向。只轉藍格內文字，不轉牆面、格子、QR 或整體輸出映射；記分板維持原方向。10/13 後續隔離 GPU 回歸 162 項與真實工作台 GUI 回歸 32 項通過，預設 CAVE 左牆完整可見；原 `EndLayoutGroup` 錯誤在本次隔離 GUI 操作中未重現，根因仍未確認。Player 與實體安裝方向仍待驗收。正式設定使用 `704_Output.asset`；`704_Output_UNCALIBRATED.asset` 是歷史占位資料。執行期後台顯示於主螢幕，場域 atlas 只送至第二顯示器。

目前五關版直接開 EXE 或 `啟動場域輸出.cmd` 即啟動雙螢幕模式，無需 `--output`。若找不到第二台顯示器，程式會將場域輸出退回主螢幕並記錄警告；這種單螢幕 fallback 尚未做人工操作驗收。

## TouchService 與驗證

遊戲預設訂閱 `ws://127.0.0.1:20111/`。不搶感測器原始 UDP 20001，也不自動啟動或修改既有服務。可用 `--touch-uri ws://127.0.0.1:其他埠/` 指定測試服務。

驗證報告與截圖放在 [TestResults](TestResults)。最新隔離 GPU 完整 `ProductionVerification` 為 163 項通過；10/12 的 151 項方向檢查未覆蓋最終 atlas 面映射，不能作方向驗收依據。較早基礎檢查 48 項、匯入檢查 89 項、真實工作台 GUI 12 項為各自歷史結果；VenueHud_04 交付版當時另有 37 項工作台／規則、8 項記分板 HUD、7 項工作台 GUI 及交付路徑 106 項 Player 自測通過紀錄。本次沒有重跑 Player 或 18 項 QR 專項。本次 Player 四張場域輸出截圖各取樣 5,475 點，與等比例參考 0 mismatch；DPI-aware 主螢幕完整包含檢查也在交付 Player 自測通過。QR 獨立解碼使用 2688×3840 場域 atlas，未驗證實體掃碼機。觸控／掃碼為模擬輸入，實體掃碼機、TouchService、長時間現場穩定性、704 場域投影路由與 QR 至少 20 cm² 的物理面積仍待驗收。詳見[驗證狀態](docs/VALIDATION.md)。
