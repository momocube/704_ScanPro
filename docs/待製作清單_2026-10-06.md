## 2. 直覺的每點時間設定與秒／幀換算

### 使用者需求

- [ ] 可在指定點手動輸入「停留秒數」，支援小數；希望停久一點，再快速移至另一點。
- [ ] 時間操作要直覺，方便知道某個幀數對應多少秒。對話中的「偵數」在本清單按「幀數（frame）」理解。

### 實作狀態

- 起點與各路徑點已有可輸入小數秒的停留設定；各段移動時間仍沿用每關的 `movementSegmentMs`，包含回到起點路段。
- 秒數／幀數可雙向換算，基準 FPS 為關卡欄位、預設 60。換算不會以幀數四捨五入覆寫秒數。
- 37 項工作台／規則檢查已涵蓋各點停留及 FPS 換算；下方工作台操作核對仍待人工驗收。
- [ ] 起點與每個路徑點皆納入停留設定，`0` 秒代表不停留。
- [ ] 秒／幀欄位雙向換算：`秒數＝幀數÷換算 FPS`；`幀數＝秒數×換算 FPS`。
- [ ] 換算使用關卡設定的固定 FPS，實際路徑仍按經過秒數計算；不依電腦當下 FPS 改變節奏。預設為 60 FPS，可調整。
- [ ] 小數秒不必強制對齊整數幀；遇到非整數幀清楚標示，不能暗中四捨五入改掉使用者設定的停留秒數。
- [ ] 建議顯示累計到達／離開時間、單次循環總長，提供預覽秒／幀定位與前後逐幀查看。

示例僅用來說明欄位語意，不是正式關卡設定：

| 點 | 累計到達時間 | 在此停留 | 移到下一點 |
| --- | ---: | ---: | ---: |
| 起點 | 0 秒 | 2 秒 | 0.2 秒 |
| A | 2.2 秒 | 1.5 秒 | 0.3 秒 |
| B | 4 秒 | 0.5 秒 | 0.2 秒回起點 |

此例單次循環為 4.7 秒。60 FPS 下 150 幀＝2.5 秒；此為目前編輯器換算預設，不影響以秒儲存的停留時間。

### 相容與驗收

- [ ] 舊關卡缺少新欄位時，停留為 0，移動沿用原設定；不要在載入時改寫關卡。
- [ ] 點的插入／刪除／重排後，時間仍對應正確的點或路段；鏡射、複製、拖曳整條路徑時一併保留時間。

## 3. 在增加路徑點模式內完成一條路徑，再切換其他物件

### 使用者需求與已實作流程

- 完成一個物件的路徑後可直接接著處理另一個物件，不必在「選取」「增加路徑點」兩個工具間來回切換。
- 已提供「完成路徑」按鈕及 Enter 快捷鍵；結束後留在增加路徑模式，點另一個物件可開始編輯其路徑。工作台程式檢查通過，人工操作仍待驗收。

### 操作流程

1. 留在「增加路徑點」模式，尚未編輯物件時點選藍格 A。
2. 進入 A 的路徑布置狀態，連續點擊有效場地新增路徑點。
3. 布置期間即使點到 B 藍格所在位置，也新增 A 的路徑點，不自動切換物件。
4. 按畫布上方固定可見的「完成路徑」，或 Enter，結束 A 的路徑布置。
5. 工具仍維持「增加路徑點」模式，回到等待選取下一個物件；點 B 即開始 B 的路徑。

`選 A → 增加 A 的路徑點 → 完成／Enter → 選 B → 增加 B 的路徑點`

- [ ] 明確顯示目前正在編輯哪個物件、等待選物件或布置中，並突顯當前路徑。
- [ ] 「完成」表示結束本次路徑布置，不能自動新增一個重複終點或重複閉合點；既有循環回程由路徑設定計算。
- [ ] 「完成路徑」與「儲存關卡」分開，不暗中儲存正式關卡。
- [ ] 已有路徑的續編／修改保留原資料，不因重新選取而清空。
- [ ] 點既有節點修改時間與新增重合節點的手勢需定義清楚；Enter 在數字輸入框內應優先完成欄位輸入，避免意外結束路徑。
- [ ] 明確處理切換關卡／工具及未完成編輯，避免遺失已新增的點；新增／結束／續編均應可合理 Undo／Redo。

### 驗收

- [ ] 連續編輯 A、B、C 三個物件，全程不需切換選取工具。
- [ ] 布置 A 時點到 B 的位置不會誤換物件；完成 A 後點 B 不會誤加 A 的路徑點。
