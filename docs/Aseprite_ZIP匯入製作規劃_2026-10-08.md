## 使用者操作流程

開啟 Unity → 開啟掃碼 Pro 關卡編輯器 → 點【匯入關卡包zip檔】→ 選擇 ZIP → 自動解析並產生關卡 → 編輯器立即預覽 → 調整內容與試玩 → 保存 → 一鍵輸出 EXE。

匯入後的內容成為可編輯關卡草稿；條碼、數字／算式與互動規則在編輯器預覽／試玩即可檢查。藍格的答案內容取自 `blue_count` 子資料夾名稱，可在 Inspector 調整；遊玩仍按答案升冪完成。

## 第一階段：ZIP 匯入入口與版本資訊（已實作）

- 在現有工作台加入【匯入關卡包zip檔】按鈕，開啟檔案選擇視窗。
- 工作台按鈕選 ZIP；在記憶體內檢查 ZIP 路徑、PNG、檔案數與解壓大小，再直接建立獨立草稿，不展開或覆寫來源素材。
- 速度由 ZIP 檔名的 `(350ms)` 標記讀取；若沒有則從唯一根資料夾讀取，缺少或超出 1–60000ms 時拒絕匯入。來源序列自然數排序。
- 成功後自動選取草稿、重設並顯示預覽；固定顯示 ZIP 原始檔名、台北匯入時間、轉換摘要和警告，並隨資產保存。
- 取消不改任何關卡；匯入失敗或建立草稿失敗時顯示錯誤並保留原選取關卡。再次匯入使用唯一新路徑，不覆蓋既有草稿或正式關卡。
- 格式錯誤會指出原因；無效 `blue_count` 目錄略過並警告，無速度標記或沒有可轉換 PNG 時拒絕整包。

驗證狀態：匯入 API、缺少速度／無效答案格式及草稿保存／重開已自動驗證；取消分支目前由程式在選檔對話框回傳空路徑時直接結束，尚未在 Unity GUI 人工點選驗收。工作台完整人工操作仍待驗收。

## 第二階段：解析並轉換成遊戲資料

| 包內內容 | 轉換結果 |
| --- | --- |
| `basic.png` | 綠色安全區；檔案在 ZIP 根目錄。 |
| `frames/1.png、2.png…` | 逐幀紅色危險區，同步更新畫面與碰觸範圍。 |
| `blue_count/答案/影格.png` | 答案為非負整數或有效加減式；位置及影格遮罩來自 PNG，答案文字可編輯。 |
| `blue_scan/名稱/影格.png` | 掃碼藍格，場景建立隨機 QR 目標；資料夾內影格組成同一序列。 |
| `trigger/機關/from/影格.png` 與 `to(clearwrong).png` | 紫色機關動畫及區域遮罩；遮罩與匯入紅色標記重疊的紅區相連。 |
| `shutter/機關_shiftRed|shiftGreen/` | 淺藍掃碼機關與排序的狀態組；每次掃描前進並循環。`shiftGreen` 依圖片位置轉換，不套用 Floor 限制。 |

- 區域不以標記顏色推斷機關類型：排除黑、白及 RGB `(50,50,50)`、`(100,100,100)`、`(162,161,160)` 後，其他 RGB 顏色都有效；alpha 不參與判斷。
- 來源圖統一以最近像素取樣、非等比例鋪滿 520×420；同一資料夾的圖片依自然數排序視為序列。單張圖以上下左右連通分區，斜角相碰分開。
- 每關只有一個動畫速度，套用所有物件與機關影格；可見影格同時定義互動遮罩。已完成藍格不因動畫循環重新出現。
- 紫格長按達目前設定門檻後，按住多久皆維持效果；只讓 `to(clearwrong).png` 遮罩與連結紅區／`frames/` 的實際重疊範圍透明，未被遮罩覆蓋的圖案與碰觸效果保留，清除區露出下層，放開後恢復。匯入器保存來源遮罩；沒有該欄位的舊草稿以紫格圖形作局部清除範圍。`shiftGreen` 的安全區位置照圖轉換，可出現在 Floor 以外；仍受場域可放置範圍與固定入口／記分板禁區限制。

2026-10-12 以原始 `1-3 (100ms).zip` 新增精確遮罩草稿 `Assets/ScanPro/LevelDrafts/Imported_1-3 (100ms) - ClearMask.asset`；原有草稿保留未覆寫。工作台選擇名稱含 `ClearMask` 的版本，可驗收來源 `to(clearwrong).png` 遮罩；遮罩與四個相關 frames 群組只在實際重疊處清除。隔離匯入紀錄見 `TestResults/PurpleMaskFix_20261012/reimport-1-3.log`。
